# 内容简介

## 有些故障不会报错

最贵的线上事故，往往没有一条 ERROR 日志。

库存多扣了 347 件，订单表干净，接口全 200；用户改了昵称，三小时后才生效；消息 `send success`，对端却从未收到；监控上错误率 0.00%，客诉 40 单。代码看起来完全正确，框架按文档工作，SQL 也执行了——**错的只有数据**。而数据错了，要等到对账、客诉、或者第二天早上，才有人知道。

《Java 后端故障图鉴》解剖的正是这一类故障：不抛异常、不告警、不出现在任何下游监控面板上，却让结果悄悄偏离预期的「静默失效」。

## 不教原理，教「为什么你的原理没生效」

讲原理的书很多：事务是什么、索引怎么走、消息队列如何保证投递。可线上出事时，问题几乎从不是「不知道这个概念」，而是「以为它按我想的方式工作了」。

所以这本书不铺知识点，只做一件事：**把一次静默失效从现场还原到根因，再把根因变成一条能复用的判据**。每一章都从具体时间线开始，如实保留当时判断错在哪里——「我们当时以为是 X，其实是 Y」是这类书里最值钱、也最常被删掉的部分。

## 五个母题

二十七章走完，散落的故障收敛成五个母题：

- **你以为执行了，其实没执行**——事务没开、锁没生效、切面被绕过；框架按契约工作了，只是那个契约不是你以为的那个。
- **你以为传过去了，其实变形了**——Long 精度、时区差 8 小时、金额丢末尾的 0；跨边界时类型系统和语义一起失效。
- **你以为很快，其实在排队**——连接池、线程池、行锁、MQ 积压；「慢」多半不是算得慢，是等得慢，而等待不出现在下游面板上。
- **你以为处理了一次，其实两次或零次**——重试、重复消费、幂等缺失；「至少一次」是异步世界的默认语义。
- **你以为监控看得见，其实它瞎了**——错误率 0 不等于没错，`send success` 不等于送达；可观测性只覆盖你想到的维度。

它们的共同点只有一句：**系统没有报错，是你在用错误的假设读它。**

## 按一次事故的顺序，而不是按技术分层

全书五卷二十七章，沿读者真实经历的那条线排：

- **卷一　请求进来（1–5）**——37 毫秒里的观测点、超时与重试、序列化陷阱、连接池耗尽、网关限流
- **卷二　业务跑起来（6–11）**——事务静默失效、事务里做远程调用、循环依赖、线程池、并发可见性、异常处理吃堆栈
- **卷三　数据落地（12–17）**——索引失效、深分页与慢 SQL、锁与死锁、缓存一致性、缓存三大问题、分库分表
- **卷四　异步与峰值（18–22）**——消息丢失、重复消费与幂等、积压处置、顺序消息、秒杀库存扣减
- **卷五　上线之后（23–27）**——CPU 100%、OOM 取证、GC 停顿与 P99、容量与压测、故障复盘

顺着读是一条完整的排查训练；跳着读也成立——前言里有一张「你正在经历什么 → 读哪几章」的索引。

## 一章里有什么

每章固定六段：**现场 → 误判 → 根因 → 修复 → 自检清单 → 延伸**。「修复」必有 ❌ 错误写法 → ✅ 修复写法的对照，「自检清单」可以直接贴进 CR 模板。

章内按难度标【必读】【进阶】【选读】：3–5 年读者吃透主线即可；想从「会用」走到「懂为什么」再往下看框架源码、量化推演与边界条件。全书还埋了九条跨章主线（Little's law、超时链路、行锁持有时间、幂等、缓存一致性、对账兜底等），主场章节讲透原理，其它章只引用不重述，书末附章号映射表。

书里的现场由多个真实故障脱敏合成，代码、数字与时间线经过改写，但结论对应真实的排查路径。配套 27 章可运行代码另放在 `book-demo/`，书中说「能跑」的验证代码都经过编译与实跑。

## 写给谁

写给**已经在线上扛过责任**的 Java 后端：工作 3–5 年，第一次撞上「本地跑得好好的」，或者踩过、想看清机制为什么这样设计。

不写给准备面试、需要知识覆盖面的人；也不写 Java 语法、框架用法、架构方法论——那些有更好的去处。这本书只回答一个问题：**当系统不报错、但结果是错的时候，怎么找到原因。**

5 卷 27 章，约 13 万汉字正文（含代码与表格版面约 25 万字），170×240 mm 排版；代码与配置基于 JDK 17/21、Spring Boot 3.x、MySQL 8.0、Redis 7.x、RocketMQ 5.x / Kafka 3.x。

本册为**初稿**，27 章均已扩写到成书密度、全部处于 review 状态，尚待技术复核与三审三校。框架默认值会变，但「默认值是给 demo 用的」这条判断不会变——看到具体数值请以手上的版本文档为准，看到判断逻辑可以直接用。
